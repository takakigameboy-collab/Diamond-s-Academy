PT/BR:

Este website foi desenvolvido como projeto prático para a disciplina de Projeto disciplinar do curso de Cientista de dados. 
O objetivo principal é simular a interface e as funcionalidades básicas de uma plataforma digital para academias. 
Devido ao cronograma restrito de desenvolvimento, o escopo inicial foi concentrado na estrutura essencial (MVP - Produto Mínimo Viável).
Por essa razão, algumas seções operam como protótipos funcionais, prontas para receberem futuras expansões de conteúdo e refinamento de código."


INGLES:

This web application represents the foundational architecture of a gym management and customer engagement platform. 
Developed under strict time constraints, the project focuses on establishing a clean user interface (UI) and core navigation paths.
